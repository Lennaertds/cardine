# Desktop — landing page, keyboard

> **Role:** What only the desktop showcase asks on top. The floor for all surfaces is in shared.
> **Not here:** the floor ([a11y.md](../shared/a11y.md)).

## 1. Order

Visible focus follows the page: bar → first CTA → sections → footer.

- Section dots activate with Enter and Space.
- A marquee or moving block has a pause, stops on focus, and stands still under reduced-motion.
- Headings go H1 → H2 → H3 without a skip. [type.md](landingpage/type.md).
- A meaningful image has alt text. A decorative image has `alt=""`.
- An icon next to a visible label is `aria-hidden`. An icon button has a name. [icons.md](landingpage/icons.md).

## 2. Pointer

- No `(pointer: fine)` → no hover target, no custom cursor, no magnetic. Then the phone landing path applies (one column, no cinematic).
- The custom cursor is off under reduced-motion and on keyboard focus.
- Text scales with the browser. Layout in `rem`. The claim band may wrap; it may not clip.
- A 768px wide window shows the content in one column, without horizontal page scroll.

**Test:** Tab through the landing page without a mouse. The claim stays readable on the bar photo or does not touch the bar. Focus is not hidden under the bar.
