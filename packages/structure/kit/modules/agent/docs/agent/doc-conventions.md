# Docconventies

> **Rol:** Hoe je een doc in dit project schrijft.
> **Niet hier:** waar een doc hoort ([INDEX.md](../INDEX.md)).

- **Kopregel.** Elk doc begint met `# Titel`, een regel `> **Rol:**` en een regel `> **Niet hier:**` met een link naar waar het aanpalende wel staat.
- **Eén feit, één plek.** Herhaal niets; link naar de plek waar het staat.
- **Geen afgeleide kennis.** Geen mappenbomen, bestandslijsten of versienummers die je uit de code kan halen.
- **Bewust later (P28).** Lever je een architecture-onderwerp bewust incompleet op: vaste kop `## Bewust later` met tabel *uitbreiding · waarom later · vraag als*. Stil weglaten mag niet.
- **Tabellen** voor opsommingen van gelijke dingen; proza voor redeneringen.
- **Toon:** <bv. Nederlands, actief, "je">. Termen uit [GLOSSARY.md](../context/GLOSSARY.md).
- **Lengte:** past een doc niet op twee schermen, dan splits je per vraag.
