# Inbox — nog geen vaste plek

## 2026-11-19 — Kit-profielen

Idee van Ventje: meerdere kit-"profielen" voor verschillende soorten projecten, i.p.v. één universele kit.

### Gewenste profielen

1. **App** (applicatie bouwen) — zoals huidige kit voor GymFreak, Caddie
2. **Research** (onderzoek + software) — Agent Engineering, Cardine
3. **Studie** (studieplanning bijhouden — kalender, deadlines) — nieuw
4. **Schoolwerk** (oefeningen DL/DB/Python/algo — basic scripts, Podman/Docker containers) — nieuw

### Opmerkingen

- "App" heeft geen onderverdeling nodig: projectspecifiek pas je in het project zelf aan
- Research heeft nú al modules `research`, `assignment`, `agent`
- Studie en Schoolwerk bestaan nog niet als profiel
