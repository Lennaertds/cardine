# Open modellen — weights, licenties, modificatie

> **Rol:** Wat “open” betekent, wat je mag draaien/wijzigen, en tools die gewichten aanpassen.
> **Niet hier:** inference-engines ([../inference](../inference/INDEX.md)); closed API-only producten.

## Belangrijk onderscheid

| Term | Betekenis (praktisch) |
|------|------------------------|
| **Open weights** | Gewichten downloadbaar; licentie kan gebruik/redistributie beperken |
| **Open source** (strikt) | Code + vaak weights onder OSI-achtige vrijheden; niet elk HF-model is dit |
