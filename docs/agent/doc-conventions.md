# Doc conventions

> **Role:** how to write a doc in this project.
> **Not here:** where a doc belongs ([INDEX.md](../INDEX.md)).

- **Header block.** Every doc starts with `# Title`, a `> **Role:**` line and a `> **Not here:**` line linking to where the adjoining material does live.
- **One fact, one place.** Repeat nothing; link to where it lives.
- **No derived knowledge.** No directory trees, file lists or version numbers you can read from the code.
- **Deliberately later (P28).** When you deliver an architecture topic deliberately incomplete: fixed heading `## Deliberately incomplete` (P28) with the table *extension · why later · ask when*. Silently omitting is not allowed.
- **Tables** for lists of equivalent things; prose for reasoning.
- **Tone:** English, active, "you". Terms from [GLOSSARY.md](../context/GLOSSARY.md).
- **Length:** if a doc does not fit on two screens, split it by question.
