# Doc conventions

> **Role:** How to write a doc in this project.
> **Not here:** where a doc belongs ([INDEX.md](../INDEX.md)).

- **Header.** Every doc starts with `# Title`, a line `> **Role:**` and a line `> **Not here:**` with a link to where the neighbouring material does live.
- **One fact, one place.** Repeat nothing; link to where it is.
- **No derived knowledge.** No folder trees, file lists or version numbers you can get from the code.
- **Deliberately later (P28).** When you deliver an architecture topic deliberately incomplete: fixed heading `## Deliberately later` with the table *extension · why later · ask when*. Silently omitting is not allowed.
- **Tables** for lists of similar things; prose for reasoning.
- **Tone:** <e.g. English, active, "you">. Terms from [GLOSSARY.md](../context/GLOSSARY.md).
- **Length:** if a doc does not fit on two screens, split it per question.
